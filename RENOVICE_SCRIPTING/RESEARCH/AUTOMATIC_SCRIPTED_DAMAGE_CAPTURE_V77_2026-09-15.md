# Automatic scripted-damage capture V77 — 2026-09-15

## Objective

Capture damage from every loaded Luau source that uses the authoritative
per-target `DamageDD` boundary without manually embedding a battle logger in
each ability. Preserve exact source isolation and make the coverage boundary
visible instead of calling an area request or native-only path complete.

## Implemented architecture

1. `DiagnosticsDamageCapture=scripted` requests the exact `DamageDD` native
   adapter even when the managed-addon set is empty.
2. Successful natural module loads publish immutable prototype identities with
   body key, path/name, prototype ID, code range, and VM ownership.
3. At native ingress, the adapter resolves the closest cataloged Luau caller,
   reads the target's engine type, and applies exact configuration filters.
4. Target-addon `before` providers run first. Automatic observation then reads
   the installed packet, stock `DamageDD` executes once, automatic observation
   reads final target state, and target-addon `after` providers run last.
5. The automatic Luau runtime embeds the exact canonical
   `CombatTransactionBattleLogV5.luau` prefix. Its generated bytecode is rooted
   once per VM in the existing DE registry lifecycle.
6. F9 resets the bounded budget, reconciles the trace root and native adapter
   contract, and updates source/type/damage filters without touching ability
   files.

## Isolation fields

- `DiagnosticsTarget`: exact source body key during automatic capture.
- `DiagnosticsDamageSource`: exact module path or module name.
- `DiagnosticsDamageTargetType`: exact engine receiver type name.
- `DiagnosticsDamageType`: exact numeric nonzero packet fraction, 0 through 19.
- `DiagnosticsMethod`: blank or exact `DamageDD` for the automatic lane.
- `DiagnosticsAddon`: must remain blank because the automatic lane is not an
  addon provider.

The analyzer exposes `AutoSequence`, `SourceBody`, `SourcePath`, `SourceName`,
`SourcePrototype`, `SourceInstruction`, and `TargetType` and accepts exact
source-body, source-path/name, and target-type filters after capture.
